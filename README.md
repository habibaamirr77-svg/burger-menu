# Monte seu lanche — منشئ الساندوتش والبطاطس

موقع ثابت (HTML + CSS + JavaScript) من غير أي مكتبات أو سيرفر.
افتح `index.html` في المتصفح وهيشتغل.

## هيكل الملفات

```
burger-site/
├── index.html          هيكل الصفحة
├── css/
│   └── style.css       كل التنسيقات (وضع فاتح/غامق، RTL/LTR)
├── js/                 (الترتيب مهم — بنفس ترتيب <script> في index.html)
│   ├── data.js         بيانات المنيو: المكونات، العيش، أحجام البطاطس، الأسعار
│   ├── i18n.js         النصوص بالعربي والإنجليزي
│   ├── state.js        حالة التطبيق + حساب الإجمالي (من غير DOM)
│   ├── render.js       رسم الواجهة وترتيب الطبقات
│   └── app.js          الأحداث (اللغة، التابات، الطلب) والتشغيل
└── assets/images/
    ├── ingredients/    صور المكونات (PNG شفاف)
    └── buns/           صور العيش (علوي wt/gt وسفلي wb/gb)
```

## تعديلات شائعة

- **تغيير سعر أو حجم صورة مكوّن:** `js/data.js` ← `INGREDIENTS` (`price`, `w`, `h`, `ph`).
- **إضافة مكوّن جديد:** حط صورته في `assets/images/ingredients/`، وضيف سطر في `INGREDIENTS`، وضيف الـ id بتاعه في `SETS`، وترجمته في `js/i18n.js` تحت `ing`.
- **تغيير العملة:** `CURRENCY` في `js/data.js`.
- **تغيير الألوان:** المتغيرات في أول `css/style.css`.
